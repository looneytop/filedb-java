# Двоичный формат — заготовка спецификации

Формат ещё не утверждён. До написания хранения нужно заполнить этот документ.

## Общие правила

- [ ] Выбрать поля, их Java-типы и представление на диске.
- [ ] Установить порядок байтов.
- [ ] Определить предельные длины строк в байтах UTF-8 и хранение их длины.
- [ ] Установить сигнатуру и версию формата.
- [ ] Выбрать значение, означающее отсутствие адреса.
- [ ] Определить проверки некорректного или неполного файла.

## Файл данных

- [ ] Поля заголовка, размеры и смещения.
- [ ] Признак занятого / свободного слота.
- [ ] Состав и полный размер слота.
- [ ] Формула адреса слота.
- [ ] Представление списка свободных слотов.
- [ ] Порядок обновления записи и служебных данных.

## Файлы индексов

- [ ] Заголовок: версия, тип поля, корень, свободные узлы.
- [ ] Представление ключа.
- [ ] Адрес записи, дочерних узлов и высота.
- [ ] Размер узла, адресация и переиспользование удалённых узлов.
- [ ] Порядок обновлений при поворотах и удалении.

## Проверки

- [ ] Пустая база; первая запись; повторное открытие.
- [ ] Максимальная длина строки и её превышение.
- [ ] Повтор ключа; одинаковые неключевые значения.
- [ ] Удаление и повторное использование места.
- [ ] Редактирование ключа и индексируемых значений.
