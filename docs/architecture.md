# Согласованная архитектура

## Слои

Swing GUI → DatabaseService → RecordFile / FileAvlIndex → файлы.

GUI показывает данные и вызывает сервис. Сервис проверяет ограничения и
координирует изменение записей и всех индексов. Формат одной записи описывает RecordCodec.

## Хранение

- Один файл данных со слотами фиксированного размера.
- Заголовок с версией формата, размером слота и адресом свободного места.
- Свободные слоты связаны в список; добавление не ищет их полным проходом.
- Строковые поля имеют проверяемый предел в байтах UTF-8.
- Узлы AVL и адрес корня хранятся в служебных файлах.
- Индекс по каждому полю, которое поддерживает поиск в GUI.
- Ключевой индекс проверяет уникальность.
- Для повторяющихся значений неключевого поля возможен ключ (значение поля, id).
- Файл записей и индексы целиком не загружаются в рабочие коллекции.
- Коллекция результатов для GUI допустима; изменения идут через файловое хранилище.
- Операции одного открытого хранилища выполняются последовательно.
- Перед backup завершить текущую операцию и на время копирования исключить изменения.
- Сохранение фиксирует метаданные и сбрасывает файловые буферы.

## Целевые оценки, ещё не подтверждённые реализацией

n — число записей, k — число совпадений. Размер записи и число индексов ограничены.

| Операция | Цель |
| --- | --- |
| Поиск по ключу | O(log n) |
| Добавление / удаление / редактирование одной записи | O(log n) |
| Поиск всех совпадений по индексируемому неключевому полю | O(log n + k) |
| Удаление всех k совпадений с обновлением индексов | O((k + 1) log n) |

Для поиска всех совпадений нужен обход диапазона, а не k отдельных поисков от корня.
Открытие/сохранение не должны скрыто перестраивать все индексы.
Полный просмотр, backup и экспорт зависят от объёма данных.
Перечитывание всей БД ради обновления GUI не включать в каждую операцию.

## Пока не определено

Предметная область, окончательные поля, ограничения значений и точный двоичный формат.
Не принимаем пример с книгами за готовую схему.

## Порядок реализации

1. Выбрать поля и формат записи.
2. Реализовать RecordCodec и проверить одну запись.
3. Реализовать RecordFile, заголовок и свободные слоты.
4. Реализовать файловый AVL-индекс.
5. Добавить операции DatabaseService и проверки согласованности.
6. Подключить GUI и операции управления БД.
7. Реализовать backup, восстановление и экспорт.
8. Провести замеры и заполнить отчёт.
