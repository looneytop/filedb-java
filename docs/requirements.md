# Требования лабораторной

Источник: ТЗ, присланное Сергеем 31.10.2026.

- Собственная однотабличная файловая БД с графическим интерфейсом.
- Не менее четырёх столбцов четырёх различных типов; хотя бы один уникальный ключ.
- Создание, открытие, удаление, очистка и сохранение БД.
- Добавление записи с проверкой уникальности ключа.
- Поиск по ключевому и неключевому полю с выводом всех совпадений.
- Удаление по ключевому и неключевому полю; для неключевого удалить все совпадения.
- Редактирование записи с сохранением ограничений и корректности индексов.
- Создание backup и восстановление.
- Экспорт в сторонний формат (.xlsx) — пункт со звёздочкой.

## Ограничение хранения

Работа ведётся с файлом данных и/или служебными файлами.
Загружать строки в коллекцию, выполнять операции с коллекцией и затем переписывать
файлы запрещено. Исключение — данные для визуализации, но операции над записями
всё равно проходят через исходное файловое хранилище.

## Оценивание и сдача

Нужны исходники, демонстрация с ответами по реализации и отчёт.
В отчёте — предметная область, временные замеры и анализ добавления, удаления, поиска.

Линейные операции — до 5 баллов (иногда до 6 при дополнительном функционале).
Быстрый поиск с медленными изменениями — до 7.
Логарифмические и более эффективные операции — ориентир 8–10, без гарантии оценки.

SQL и подключение готовой СУБД в требования не входят.
