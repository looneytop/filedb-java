# План замеров

Замеры будут после реализации и проверки алгоритмов. Фактических результатов пока нет.

- Сравнить несколько размеров БД, например 1 000 / 10 000 / 100 000 записей.
- Генерацию исходной БД и показ GUI вынести за измеряемый участок.
- Для поиска проверять существующие и отсутствующие значения.
- Отдельно учитывать число совпадений k при поиске и удалении по неключевому полю.
- Для добавления учитывать проверку уникальности и обновление всех индексов.
- Проверить добавление в новый слот и повторное использование удалённого.
- Для редактирования проверить изменение индексируемого поля и ключа.
- Повторять измерения и описать прогрев JVM и влияние файлового кэша ОС.
- Указать единый режим сброса данных на диск; не сравнивать разные режимы как один.
- Записать конфигурацию среды: JDK, ОС, накопитель, ограничения строк и число индексов.
- Сопоставить время с числом посещённых узлов / файловых чтений.
- Сохранять результаты в benchmarks/results, не выдавать плановые оценки за замеры.

Сборку и запуск через Swing в тайминг операций не включать.
