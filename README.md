# Лабораторная: файловая база данных

Это отдельный Maven-модуль внутри java_practice. Сейчас подготовлен **каркас**:
главное окно запускается, а хранение, индексы и операции ещё предстоит реализовать.
Готовых алгоритмов БД здесь нет.

## Запуск

Нужен JDK 21. Maven отдельно устанавливать не требуется: в модуле есть Maven Wrapper.

Из каталога file_database_lab:

```sh
./mvnw verify
java -jar target/file-database-lab-0.1.0-SNAPSHOT.jar
```

Первая сборка скачивает Maven и зависимости из Maven Central.
На Windows вместо ./mvnw используется mvnw.cmd.
На этом этапе verify проверяет сборку каркаса; тестов алгоритмов пока нет.

В IntelliJ IDEA модуль подключается как Maven-проект через его pom.xml.
В проект добавлена конфигурация запуска **File Database Lab**.
Также можно открыть класс ru.looneytop.filedb.Main и запустить main().
Рабочий каталог приложения — file_database_lab.

## Структура

| Каталог / пакет | Назначение |
| --- | --- |
| src/main/java/ru/looneytop/filedb/model | Модель записи: поля и типы выберем следующим шагом |
| storage | Двоичный формат, чтение/запись слотов, заголовок и свободные места |
| index | AVL-деревья, узлы которых хранятся в служебных файлах |
| service | Операции БД и согласованное изменение данных и индексов |
| ui | Swing: окно и будущая таблица записей |
| backup | Копирование и восстановление согласованного комплекта файлов |
| export | Будущий экспорт в .xlsx; Apache POI подключим на этом этапе |
| benchmark | Будущие замеры операций без GUI |
| src/test | Тесты на временных файлах и тестовые ресурсы |
| data | Рабочие файлы БД; содержимое исключено из Git |
| backups | Резервные копии; содержимое исключено из Git |
| exports | Экспортированные файлы; содержимое исключено из Git |
| docs | Требования, архитектура, будущая спецификация формата и шаблон отчёта |
| benchmarks/results | Результаты замеров; содержимое исключено из Git |

## Что пишем сами

RecordCodec → RecordFile → FileAvlIndex → DatabaseService → GUI-операции.
Данные и индексы обрабатываем непосредственно в файлах.
Коллекция строк допустима для отображения, но не служит рабочим хранилищем БД.

Каталог книг был примером в обсуждении; предметная область ещё не выбрана.
Начинаем с выбора полей, затем фиксируем двоичный формат в docs/file-format.md.
